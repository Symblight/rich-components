# @symblight/editor

A Material Design 3 rich text editor web component built with [Lit](https://lit.dev).

> Work in progress — the component is currently an empty shell.

## Usage

```js
import "@symblight/editor";
```

```html
<edx-editor></edx-editor>
```

## Development

```bash
pnpm --filter @symblight/editor sb     # Storybook, port 6009
pnpm --filter @symblight/editor build
pnpm --filter @symblight/editor test
```
